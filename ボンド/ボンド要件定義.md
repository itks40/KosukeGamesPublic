# ボンド 要件定義

## 1. ゲーム概要

| 項目 | 内容 |
|------|------|
| ゲーム名 | ボンド |
| プレイ人数 | 2名 |
| 目的 | ポーカーの役でより強い手札を作り、場のチップを獲得する |

---

## 2. コンポーネント

### カード（計26枚）

| カード | 枚数 |
|--------|------|
| 9, 10, J, Q, K, A（各スート×4） | 24枚 |
| ジョーカー | 2枚 |
| **合計** | **26枚** |

> ジョーカーはワイルドカードとして扱い、任意のカードの代わりになる。

### チップ
- 各プレイヤーの初期所持数: **10枚**

---

## 3. セットアップ

1. **先攻/後攻の決定**: ジャンケン等で先攻・後攻を決める。
2. **場代の徴収**: 各プレイヤーがチップを1枚ずつ場に出す（場のチップ計2枚）。
3. **カードのシャッフル**: 26枚全てをシャッフルする。
4. **手札の配布**: 各プレイヤーに5枚ずつ配る。残り16枚は山札として中央に置く。
5. **捨て札の準備**: 山札の横に捨て札置き場を用意する（最初は空）。

---

## 4. ゲームの流れ

```
先攻ターン1 → 後攻ターン1 → 先攻ターン2 → 後攻ターン2 → 手札公開 → 勝敗判定
```

各プレイヤーが**2回ずつ**ターンを行った後、手札を公開して勝敗を決める。

---

## 5. ターンでできるアクション

1ターンの中で以下のアクションを**任意の組み合わせで実行できる**。順番は任意。

```
特殊アクション（ロブ・ダウト）→ 通常アクション（捨てて引く）の順を推奨
```

### 5-1. ロブ（任意）

**相手の捨て札から好きなカードを奪い、自分の手札を捨てる。**

1. 相手の捨て札（全て表向き公開）から、奪いたいカードを任意の枚数選ぶ。
2. 奪ったカードを自分の手札に加える。
3. 奪った枚数分、自分の手札から選んで自分の捨て札に出す。

> **補足:** 手札枚数は変わらない（奪った枚数 = 捨てた枚数）。

### 5-2. ダウト（任意）

**相手の手札に含まれるジョーカーの枚数を宣言する。**

1. 相手の手札のジョーカー枚数を「0枚」「1枚」「2枚」のいずれかで宣言する。
2. 相手は即座に手札を公開して確認する。

#### 成功（宣言が正しかった場合）
- 相手のジョーカーを全て奪い、自分の手札に加える。
- 奪ったジョーカーの枚数分、**自分の手札**から選んで相手に渡す。
- 双方の手札枚数は変わらない。

#### 失敗（宣言が外れた場合）
- 自分の持ちチップの **1/3（端数切り捨て）** を場に置く。
- チップが0枚の場合、ペナルティは0枚（支払い免除）。
- 手札に変化なし。

| 持ちチップ | 支払い枚数 |
|-----------|-----------|
| 1〜2枚 | 0枚（切り捨てで0） |
| 3〜5枚 | 1枚 |
| 6〜8枚 | 2枚 |
| 9〜11枚 | 3枚 |

> **補足:** 1ターンにロブとダウトを両方使うことができる。

### 5-3. 通常アクション（任意）

**手札を任意枚数捨て、同じ枚数を山札から引く。**

- 0枚を選んでもよい（パス）。
- 手札全枚数（5枚）まで捨てて引くことができる。

> **山札切れの場合:** 自分の捨て札を裏向きにシャッフルして新しい山札とする。それも無ければ、引けなかった分は引かずに終了。

---

## 6. 手札公開・勝敗判定

4回のターン終了後、両者同時に手札5枚を公開する。

- **ポーカーの役**が強い方が勝利。
- 勝者は**場のチップを全て獲得**する。
- **引き分け**（同じ役・同じ強さ）の場合、場のチップは次のゲームへ持ち越す（場代に加算される）。

---

## 7. ポーカー役一覧

使用カード: 9, 10, J, Q, K, A + ジョーカー（ワイルド）

| 強さ | 役名 | 内容 |
|------|------|------|
| 1（弱） | ハイカード | 役なし。最強カードで比べる |
| 2 | ワンペア | 同じ数字2枚 |
| 3 | ツーペア | 同じ数字2枚×2組 |
| 4 | スリーオブアカインド | 同じ数字3枚 |
| 5 | ストレート | 数字が5枚連続（9-10-J-Q-K, 10-J-Q-K-A等） |
| 6 | フラッシュ | 同じスート5枚 |
| 7 | フルハウス | スリーオブアカインド＋ワンペア |
| 8 | フォーオブアカインド | 同じ数字4枚 |
| 9 | ストレートフラッシュ | 同スートで5枚連続 |
| 10（強） | ロイヤルストレートフラッシュ | 同スートで 10-J-Q-K-A |

#### 役が同じ場合の比較
- 数字の強さ: 9 < 10 < J < Q < K < A
- 例: AのワンペアはKのワンペアに勝つ。
- ジョーカーで構成した役の強さは、最強の組み合わせで計算する。

---

## 8. チップ処理まとめ

| タイミング | 処理 |
|-----------|------|
| ゲーム開始時 | 各プレイヤーがチップ1枚を場に出す（場に計2枚） |
| ダウト失敗時 | 失敗したプレイヤーが持ちチップの1/3（切り捨て）を場に出す |
| 勝利時 | 勝者が場のチップを全て獲得 |
| 引き分け時 | 場のチップはそのまま次のゲームへ持ち越し |

---

## 9. 特殊裁定

### 山札切れ
通常アクションでドローしようとした際に山札が足りない場合:
1. 自分の捨て札（直前に捨てたカードを除く）をシャッフルして山札とする。
2. それでも足りない場合は、引けなかった分の枚数はドローせずにターンを終了する。

### チップが0枚の時にダウト失敗
- ペナルティは0枚（支払い不要）。

### ジョーカーが全て山札にある場合
- ダウトで「0枚」を宣言すれば必ず成功するが、奪えるジョーカーも0枚なので実質無効果。

---

## 10. ゲーム終了

以下のいずれかの条件を満たした時点でゲーム終了となる。

| 条件 | 内容 |
|------|------|
| チップ切れ | いずれかのプレイヤーの持ちチップが0になった |
| 5試合終了 | 5試合（ショーダウンまで）を終えた |

- チップが多い方を最終勝者とする。
- チップが同数の場合は引き分け。
