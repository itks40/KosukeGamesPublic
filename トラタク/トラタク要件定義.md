# トライアングル・タクティクス 要件定義書

## 1. ゲーム概要

| 項目 | 内容 |
|------|------|
| ゲーム名 | トライアングル・タクティクス（トラタク） |
| プレー人数 | 3人 |
| ゲームの種類 | 推理・情報収集カードゲーム |
| コンセプト | 質問と回答から場の伏せカードを推理して当てる |

---

## 2. コンポーネント

- トランプのJ・Q・K 各4枚、計 **12枚**

---

## 3. ゲームの目的

場に伏せられた3枚のカードが何かを推理し、「コール」を宣言して当てることでポイントを獲得する。複数ラウンドを通じて最も多くのポイントを獲得したプレーヤーが勝利する。

---

## 4. ゲームの準備

1. 12枚のカードをよくシャッフルする。
2. 各プレーヤーに3枚ずつ配る。プレーヤーは自分の手札のみ確認できる。
3. 残り3枚を**場に伏せて**置く。この3枚が推理の対象となる。

```
場の伏せカード: [?] [?] [?]

プレーヤーA: 3枚（非公開）
プレーヤーB: 3枚（非公開）
プレーヤーC: 3枚（非公開）
```

---

## 5. ターンの進行

### 5-1. 質問フェーズ

- 質問者は**時計回り**で交代する。
- 質問者は他の2人に対して**同じ質問**をし、両者がそれぞれ答える。
- 質問の形式：

  > 「**[J / Q / K]** を **[1 / 2 / 3]** 枚持っていますか？」

  例：「Jを2枚持っていますか？」

- 回答者は自分の手札に基づき**正直に**答える（持っている枚数を答える）。

### 5-2. コール宣言

- 質問フェーズ中、いつでも場の伏せカード3枚が何かわかったと判断したプレーヤーは「**コール**」を宣言できる。
- コール宣言は自分のターン（質問権）に関係なく行える。

### 5-3. コール後の宣言

- 誰かがコールを宣言したら、残り2人は**時計回り**の順に「コール」または「フォルド」を宣言する。
- 複数のコール者がいた場合、**優先順位の低い順**にカード名を宣言する。

---

## 6. コールの優先順位

| 優先順位 | 対象 |
|----------|------|
| 1位（最高） | その時点の質問者 |
| 2位 | 次の質問者（時計回りで次） |
| 3位（最低） | 次の次の質問者（時計回りで次の次） |

複数のコール者がいた場合、**優先順位3位 → 2位 → 1位**の順に伏せカードを宣言する。

---

## 7. 得点計算

| 結果 | 得点 |
|------|------|
| コール・正解 | **+2ポイント** |
| コール・不正解 | **−1ポイント** |
| フォルド | **±0ポイント** |

---

## 8. ラウンド終了条件

以下のいずれかを満たした時点でラウンドを終了する。

1. 誰かが「コール」を宣言した（コール処理を完了した後に終了）
2. 全プレーヤーが**2回ずつ**質問を行った（コール宣言なし）

---

## 9. ゲーム終了条件

- 複数ラウンドを繰り返す。
- ゲーム終了ラウンド数は別途決定（TBD）。
- 全ラウンド終了時点で**合計ポイントが最も高いプレーヤー**が勝利。

---

## 10. 用語集

| 用語 | 説明 |
|------|------|
| コール | 伏せカード3枚を推理して宣言する行為 |
| フォルド | コールを見送る宣言。得点変動なし |
| 質問者 | そのターンに質問を行うプレーヤー |
| 場の伏せカード | ゲーム開始時に場に置かれた推理対象の3枚 |
